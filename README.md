## 💻 Cara Menjalankan Project di VS Code

1. Buka folder `portofolio` di VS Code.
2. Buka Terminal (`Ctrl + ~` atau `Terminal > New Terminal`).
3. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```
4. Buka alamat lokal yang tampil (misal: `http://localhost:5173`) di browser Anda.

Untuk kompilasi produksi (*production build*):
```bash
npm run build
```
